# Week 3 — Data Visualization and Reporting

This project uses the Week 2 cleaned Gapminder dataset to communicate analytical insights through Python visualizations.

## Included
- `data/gapminder_cleaned.csv` — Week 2 cleaned dataset
- `data/visualization_summary.csv` — selected numerical findings
- `notebook/week3_visualization_reporting.ipynb` — Jupyter notebook
- `scripts/create_visualizations.py` — reproducible visualization script
- `visualizations/` — eight PNG visualizations
- `report/Week_3_Data_Visualization_Report.docx` — detailed report
- `requirements.txt` — dependencies

## Chart types
Bar charts, line charts, scatter plots, and heatmaps.

## Source
Gapminder: https://www.gapminder.org/data/
Dataset documentation: https://jennybc.github.io/gapminder/reference/gapminder.html
